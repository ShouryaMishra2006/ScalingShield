# ⚡ ScalingShield — Smart SQL Anomaly & Behaviour Monitoring System

> 🧠 Built during Hack36 9.0 — An intelligent, real-time anomaly detection and behaviour tracking system for database queries and user activity.

---

## 🚀 Overview

**ScalingShield** is a lightweight system that monitors SQL queries and user behaviour in real time.  
It detects anomalies, logs them securely, and provides insights into potential threats — all while maintaining developer-friendly simplicity and integration.
